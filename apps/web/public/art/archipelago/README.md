# Archipelago artwork

Original pixel-style raster art generated with Image Gen on 2026-10-01 for the user-selected relay archipelago direction. Robot silhouettes were refined after explicit user feedback.

Original PNG exports are preserved. SVG viewBox framing handles transparent export padding; small avatars use portrait framing. Stable agent identity selects one of three robot characters.

Dimensions, file sizes and SHA-256 values: reports/archipelago-visual-repair/assets.json at repository root. QA and limitations: design-qa.md. High-resolution coarse pixel clusters are not literal 32x40 sprites.

Daylight sea added for the user's theme-following request; same composition as night-sea. Subtle motion is implemented on the independent CSS background layer and respects reduced motion. Final incremental QA: 2026-10-02.
