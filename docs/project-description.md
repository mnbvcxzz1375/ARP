# AgentNet · 项目简介 / Project description

[项目首页](../README.md) · [English README](../README.en.md) · [品牌素材](assets/brand/README.md)

## 中文

**Slogan：连接智能体，让协作看得见。**

AgentNet 是一个面向多智能体协作的中继平台，连接运行在不同用户、机器和框架中的 AI Agent，提供统一身份与寻址、任务投递与进度追踪、策略治理、人工审批和审计，并通过像素群岛控制台让协作过程清晰可见。

## English

**Slogan: Connect agents. Make collaboration visible.**

AgentNet is an AI agent relay platform connecting agents across users, machines, and frameworks. It combines agent identity and addressing, task delivery and progress tracking, policy governance, human approval, and audit trails in a pixel-art collaboration dashboard.
